UIU Shuttle Service App

A sophisticated, interactive web application that provides real-time shuttle schedule information to university students and faculty. This project replaces static schedule pictures with a dynamic, mobile-friendly UI.

Key Features

Multi-Route Scheduling: Tabbed navigation to easily switch between Notun Bazar, EWU, and Kuril/300ft routes.

Live Weather Integration: Real-time temperature, wind, and humidity updates for the campus location using the Open-Meteo API.

Real-Time Dashboard: Displays the current time and date to help users plan their trips accurately.

Smart Notices: A scrolling news-ticker style banner for important announcements (e.g., schedule changes, ID requirements).

Emergency Contact: High-visibility section for immediate access to the Transport Supervisor.

Passenger Guidelines: Visual grid displaying essential rules like ID requirements, queue policies, and seating etiquette.

Responsive Design: Fully optimized for mobile devices, tablets, and desktops using Tailwind CSS.

Technologies Used

Frontend: React.js
Styling: Tailwind CSS
Icons: Lucide React
Weather Data: Open-Meteo API
